# 生图「提示词预设」改造 — 交付说明

**版本**：`miya-image-gen.js v17` ｜ `miya-imagegen-app.js v3` ｜ SW 构建 `sw-82` ｜ 日期：2026-09

---

## 一、需求

生图设置里原有两个预设：

| 位置 | 原功能 | 本次处理 |
|---|---|---|
| 上方「预设」（第 4 区块） | 保存**整套生图配置**（接口、密钥、模型、尺寸、提示词等全部打包） | **改为「提示词预设」**：只保存正向 + 反向提示词 |
| 下方「OpenAI 兼容」区块里的「接口预设」 | 只存网关/密钥/模型三元组 | **原样不动** |

改造动机：整套打包的预设会把接口密钥一起覆盖掉——只想换个提示词风格时，加载预设会连接口配置一起改，非常容易翻车。提示词归提示词，接口归接口，各自独立。

## 二、改造内容

### 1. 存储结构

- 新 key：`miya-image-gen-prompt-presets-v1`，行结构 `{name, positivePrompt, negativePrompt, savedAt}`
- 旧 key：`miya-image-gen-presets-v1`（v4.11 及之前的整套配置预设）**原样保留、不再读取**
- **自动迁移**：首次加载时若新 key 为空，自动把旧预设里的提示词部分提取进新 key —— 你以前存的预设**不会丢**，提示词直接继承过来（接口/尺寸部分随语义淘汰）
- 迁移只发生一次：新 key 一旦有数据，旧 key 永不再读，改旧 key 无效果

### 2. 行为变化

| 操作 | 改造前 | 改造后 |
|---|---|---|
| 保存预设 | 打包整套配置（含密钥） | 只取表单里的**正向 + 反向提示词**；两者都为空时拒存并提示 |
| 读取预设 | 整套配置覆盖写入（连接口一起换掉） | merge patch **只更新提示词两个字段**，接口/密钥/尺寸/开关一概不碰，表单立即回填 |
| 删除预设 | 删行 | 不变 |
| 正盯着看（同名覆盖） | ✅ | ✅ 不变 |
| 上限 24 个 | ✅ | ✅ 不变 |

### 3. UI 文案

- 区块标题：「预设」→「**提示词预设**」
- 下拉首项：「选择已存预设」→「选择已存提示词预设」
- 名称框示例：`例如：二次元·竖版` → `例如：赛博少女·夜景`
- 说明文字：「预设包含接口、提示词与尺寸等全部生图配置」→「**只保存正向与反向提示词，不影响接口、尺寸等其它配置**」
- toast：「预设已保存」→「提示词预设已保存」；「已读取」→「已载入提示词」

### 4. 顺带清理

读取预设时对 `miyaSettingsApp.markIgPresetActive` 的调用（已删除的旧设置 App 遗留钩子）一并移除。

## 三、验证

`node vm` 沙箱测试 20 项全部通过，覆盖：

- 迁移：旧整套预设 → 新提示词结构，值正确、不带 config/size；旧 key 保留；接口预设 key（`OA_PRESETS_KEY`）完全不受影响；迁移一次性（不重复迁移）
- 保存：只存正/反向提示词；两者全空拒存；同名覆盖
- 载入：表单两个文本框回填；配置中提示词更新；**接口三元组（baseUrl/apiKey/model）、尺寸、启用开关、接口类型全部原值不动**（merge patch 语义）
- 删除：删行、其余保留
- 渲染：下拉首项新文案

`node --check` 语法校验通过（两个改动文件）。
