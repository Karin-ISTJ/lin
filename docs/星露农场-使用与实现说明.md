# 星露农场（farmgame）· 使用与实现说明

桌面新增「星露农场」图标（🌱 幼苗图标）——**回合制经营小游戏**，
玩法对标小红书热传的"星露谷 Lite"海报：体力管理、每日浇水、季节轮转、升级开地。

与聊天室里的「双人小农场」（`miya-chat-farm.js`，现实时钟挂机制）**完全独立**：
两套存档、两个入口、互不干扰。

## 玩法循环

```
买种子 → 播种 → 每天浇水 → 过夜生长 → 收获入仓 → 卖出换金币 → 升级开新地
```

### v3 简洁化交互（当前版本）

- **直接点地块就干活**（不再需要先选动作按钮）：看地块状态自动判断——
  空地 → 弹出选种面板播种 · 缺水 → 浇水 · 缺肥 → 施肥（Lv.3+）· 成熟 → 收获。
- **动作按钮一键化**：`🌱 播种`＝选种后**种满全部空地**；`💧 浇水`＝全田一键浇水；
  `✨ 施肥`＝全田一键施肥；`⛏ 锄头`＝面板逐块「挖掉」或「全部锄掉」（返还一半种子钱）；
  `✨ 一键收获`保留（Lv.5）。一键操作按体力/金币**量力而行**，不够的地块自动跳过。
- **操作提示全部居中**：所有反馈（🌱 播下xx种子 / 💧 浇水提示×2 随机 / ✨ 施肥提示×2 随机 /
  ✨ 收获xx+1 / ⛏ 锄掉了xx）统一在**屏幕中间**弹出农场风木牌提示条，不再出现在地块上；
  同屏最多 2 条，自动消失。浇水**交替**说「咕嘟咕嘟，浇好啦~」「水够啦~剩下的就交给时间吧~」；
  施肥交替说「撒一把魔法肥料～」「咕嘟咕嘟，营养渗进去啦~」（不随机，A→B→A→B）。**新提示出现时上一条立即消失，同屏永远只有 1 条**。
- **播种即点即种**：播种不播进度条，点一下直接种下（浇水/施肥保留 3 秒劳作进度条）。
- **收获动效**：作物**直接消失**，地块上方冒出小小的「🍓+1」白色描边数字，
  缓缓上升淡去（一键收获逐块错开弹出）。
- **湿土可视化（去角标）**：浇过水的地块整体**变深**（湿土色遮罩），不再显示 💧 角标——
  土色深浅就是浇水状态。
- **土地贴图**：采用作者手绘风土壤贴图（草地包边 + 深棕垄沟 + 石子小花点缀，
  白底已处理为透明），观感更接近星露谷原作。
- **成熟闪烁 ✨**：作物成熟后，两颗小 ✨ 沿地块**两侧**缓缓升起渐隐（循环、错开相位，
  避开中心作物不遮挡，右上角无固定标记），提示「可以收获啦」。
- **进度条节奏**：单块浇水/施肥/锄地 1.2 秒；一键模式每块 0.9 秒波浪推进。

| 要素 | 规则 |
|---|---|
| 日历 | 1 年 = 4 季 × 14 天；季节决定当季可种作物（每季 4 种，共 16 种） |
| 体力 | 播种 2 / 浇水 1 / 施肥 2 / 锄头 1 / 收获免费；进入次日回满；Lv 每级 +2 上限 |
| 生长 | 作物 3 阶段（🌱→🌿→成熟）；**浇过水的地块过夜才长**；成熟后点击地块直接收 |
| 随机天气 | ☀️ 晴 65% / 🌧️ 雨 20%（全田自动浇透）/ 🐦 乌鸦 10%（叼走一块**没浇水**的作物）/ 🎁 拾遗 5%（捡到金币） |
| 经济 | 种子价 = 售价一半；收获经验 = 售价；金币初始 50 |
| 施肥 | Lv.3 解锁；施肥的作物收获产量 +1。右上角 ✨ 标记只在**施肥当天**显示，过夜即消失（增益保留） |
| 一键收获 | Lv.5 解锁 |
| 地块 | 初始 3 块 → Lv2/3/4 各开 1 块，上限 6 块 |
| 信箱 | 天气事件、乌鸦、换季、升级都会来信，红点提示 |
| 存档 | 每次操作自动落盘（localStorage 镜像 + IndexedDB 主存），也可手动「存档」；「重开农场」清档重来 |

## 实现要点（踩坑记录）

- **存档必须异步水合**：项目存储体系是「localStorage 镜像 + IndexedDB 主存」，
  IDB 写入确认后镜像会被替换成 `{"__storedInIdb":true}` 占位符。冷启动只做同步读会拿到空档，
  `hydrateFromIdb()`（参照美化模块的 hydrate 模式）在打开时从 IDB 取回真档，
  用 `savedAt` 比较防止旧快照覆盖新内存态。此坑实测复现过：不水合则"刷新后进度归零"。
- **每天都要浇水**：过夜结算顺序 = 乌鸦（看昨晚浇水状态）→ 生长 → 重置浇水 → 今日天气（雨天自动浇）。
  乌鸦只叼「没浇水」的作物，是可完全规避的惩罚，纯增加"记得浇水"的仪式感。
- **贴图 + emoji 混合**：横幅/地块/AI 贴图定质感，作物用 emoji（16 种 × 3 阶段若全出贴图
  需 100+ 张图且风格难统一）。真机（安卓/iOS）自带彩色 emoji 字体，显示无碍。

## 端到端实测（真实 Chromium，390×844 手机视口）

```
✓ 桌面图标存在 → 点击打开游戏
✓ 播种草莓（金币 50→45，体力 20→18）
✓ 浇水（体力 18→17）
✓ 每日浇水+过夜×2 → 第 3 天草莓成熟
✓ 收获 → 仓库草莓×1（+9 经验）
✓ 仓库卖出 → +9 金币
✓ 刷新页面后存档完整保留（IDB 水合）
===== 全流程通过，无 JS 报错 =====
```
