# 记忆表格全角兼容 · 交付说明

> 对应反馈：「怎么记忆表格又不生成了。。。没看到正文后面有记忆表格的格式」

## 一、结论先行

**生成链路本身没有坏**——注入、写入规则、回复解析、落库、楼层补写每一环都实测通过（31/31），
和上一轮「重答防雷同」的改动也无关（记忆表格相关文件此前一行未动）。

真正的问题是：**模型输出的记忆写入指令被「全角化」后，解析层认不出来，整条丢弃**。
这和这个包上一轮修的「剧情建议全角兼容」是**同一个病根**——当时修的是 plot 标签
（`miya-offline-plot.js`），记忆表格的 `<tableEdit>` 没有一起修，于是在全角化
中转/模型下，剧情建议好了，记忆表格仍然不落地。

## 二、根因：四个解析层对全角输出全部失配

不少中转/模型会把回复整体「全角化」，模型的正常输出

```
<tableEdit><!-- insertRow(1, {0:"抓到偷菜贼", 1:"胜利"}) --></tableEdit>
```

会被改写成

```
＜tableEdit＞＜!-- insertRow（1，{0：“抓到偷菜贼”，1：“胜利”}） --＞＜/tableEdit＞
```

旧实现逐层检查的结果：

| 层 | 全角形态下的表现 | 后果 |
|---|---|---|
| **标签定位** `findTableEditRange` | `/​<tableEdit>/i` 只认半角尖括号，`＜tableEdit＞` 完全失配 | 既不解析、**也不剥离** → 全角标签残留在正文，下一轮被当历史送回，模型开始照着模仿 |
| **注释剥离** `parseTableEditBlock` | `＜!-- --＞` 剥不掉 | 动作正则的结尾 lookahead（`$ | ; | \n | ,`）撞上残留的 `＜`，**整条动作被丢弃** |
| **参数解析** `normalizeCjkPunct` → `parseValue` | 全角逗号/冒号/括号早已兼容，但字符串边界 `“ ” ‘ ’` 不被当成引号 | `{0：“XX”}` 读不出值 → `reason:'args'` 失败，动作不落库 |
| **原始标记收集**（线下 dryRun 的 `mtRaw`） | 收集正则同样只认半角标签 | 候选确认时补写拿不到原始标记 → 线下记忆写入失效 |

> 注：全角逗号、全角冒号、全角括号此前已经兼容（上一轮之前就修过），
> 这次漏掉的是**全角引号（字符串边界）**和**全角尖括号（标签本身）**——
> 恰好是最容易被全角化的两类字符。

## 三、修复内容

### 1. `js2/miya-memory-table-engine.js`（v=8 → v=9）

- **`normalizeCjkPunct`**：新增全角引号配对表 `“→”`、`‘→’`。
  引号外遇到全角开引号，视为被全角化的字符串边界，归一为半角 `"` `'`；
  闭合同类配对引号时同样归一。**半角引号内的中文引号仍原样保留**
  （如 `{0:"他说“你好”"}` 不受影响），不误伤正文内容。
- **`findTableEditRange`**：标签正则改为 `/[<＜]\s*tableEdit\s*[>＞]/i`、
  闭合 `/[<＜]\s*\/\s*tableEdit\s*[>＞]/i` —— 全角标签既能解析也能剥离。
- **`parseTableEditBlock`**：注释剥离改为 `/[<＜]!--([\s\S]*?)--[>＞]/`，
  消除 lookahead 撞墙。
- **dryRun 的 `mtRaw` 收集**：改用同样的全角兼容正则，线下候选确认补写恢复有效。
- **`stripTableEditFromReply`** 兜底正则同步全角化。

### 2. `js1/miya-chat-engine.js`（v=113 → v=114）与 `js1/miya-appointment-engine.js`（v=72 → v=73）

**附带加固**：重答请求的尾部新增了「查重码」「查重块」，模型的注意力会被分走，
容易把 system 区里离得很远的记忆表收尾要求整个丢掉（表现就是「重答之后记忆表格不生成」）。
现在重答专用提示里显式补一条**格式保持**：

- nonce 消息（线上 `callWithSlice` / 线下 `buildRegenerateHintBlock`）追加：
  「本轮回复的输出格式要求与此前完全一致……仍须按【记忆增强表格·长期记忆】块的写入规则，
  在回复最末尾追加 `<tableEdit>` 记忆写入」；
- 查重块（两端 `buildRegenRejectedBlock`）同步追加该行；
- 措辞**按记忆表格开关动态切换**：总开关或「AI 写入」关闭时退回通用措辞，
  不让模型找一个不存在的规则。

### 3. `index.html` / `sw.js`

版本参数如上，`BUILD` 提至 `sw-74`，旧缓存自动失效。

## 五、给用户的补充说明

1. **更新后请强刷一次**（或等 Service Worker 自动换到 sw-74），确保 `?v=9` 生效。
2. 如果换模型/中转后仍偶发不写表，先到「记忆表格」界面确认顶部四个开关全开
   （**启用记忆表 / AI 读取 / AI 写入 / 详细写入规则**）。
3. 写入规则里有一条「无实质新信息时不要输出 tableEdit」——寒暄轮次不写是**设计行为**，
   不是故障；真正写失败时界面会 toast「记忆表：N 条写入未生效」。
4. 手动写入格式是函数调用式（不是 JSON）：
   `<tableEdit><!-- insertRow(1, {0:"值",1:"值"}) --></tableEdit>`，序号从 0 开始。
