# 卡片输出规则 · 世界书条目（可直接粘贴）

把下面 **【复制区】** 里的整段内容，粘到你新角色卡的世界书的任意一条里
（位置建议靠后、`constant` 常驻开启）。模型就会在回复末尾按格式输出卡片，
包里的渲染器会自动把它渲染成卡片。

## 【复制区】从这里开始复制

```
# 状态卡片输出规则

每次正文回复的末尾，必须输出一个状态卡片模块，用 <card> 和 </card> 包住。
标签内只允许出现本规则定义的纯文本结构，禁止使用任何 Markdown、HTML 或多余的说明文字。

固定格式如下：

<card>
[Profile|姓名|身份头衔|等级或进度|资源或声望|一句话当前心境]

[Intel]
[Pinned|单个Emoji|标签名|标题|详情|行动指引]
[Card|分类|标题|详情|行动指引]

[NPCs]
[NPC|姓名|身份称号|好感度或与我的关系|这个人的内心独白]

[Mails]
[Mail|发信人|日期|信件标题|信件正文|署名|随信物品（没有就留空）|物品说明（没有就留空）]

[Quests]
[MainQuest|主线目标名称|进度|目标说明|奖励]
[SideQuest|支线委托标题|限时或状态|委托说明|报酬]

[Todos]
[Todo|0或1|待办事项]

[Board]
[Post|发帖人|身份称号|标签|告示标题|详细说明]
[Reply|回帖人|时间|回帖内容]
</card>

## 填表要求

1. **分隔符**：每行条目内部一律用半角竖线 `|` 分隔字段，字段数量必须与上面完全一致。
2. **分区标题**：`[Intel]` `[NPCs]` `[Mails]` `[Quests]` `[Todos]` `[Board]` 这类单独成行的方括号是分区名，**不要**在里面填数据。
3. **待办勾选**：`[Todo|1|xxx]` 表示已完成，`[Todo|0|xxx]` 表示未完成。
4. **留空**：某个字段没有内容时留空即可（例如 `[Mail|老王|三日|问候|近来可好|老王||]`），但竖线要保留。
5. **条数**：只输出当前实际存在的内容。某一类确实没有时，可以整个分区不写。
6. **不要解释**：标签外不要加「以下是状态卡片」之类的话，正文写完后直接接 <card> 块。
```

## 【复制区】到这里结束

## 替换成你自己的题材

上面是通用模板。**要换成你自己的卡，只需要改两处**：

**第一处：分区名。** 比如你是侦探卡，把 `[Intel]` 改成 `[线索]`、`[NPCs]` 改成 `[相关人物]`。
渲染器认的是里面的**类型标签**（`Pinned` / `NPC` / `Card`…），分区名显示成什么它照搬什么。

**第二处：字段含义。** 比如 `[Profile|…]` 原本是 `姓名|头衔|等级|资源|心境`，
侦探卡可以当成 `姓名|代号|权限等级|信用点|心境` —— 字段**位置**保持 5 个就行，含义你自己定。

> ⚠️ 唯一要守住的：类型标签用下面速查表里的**标准名**，字段**顺序和数量**别乱。
> 想加自己的类型（比如 `[Hack|…]`）也可以，渲染器会把内容平铺显示，不会丢。

# 格式速查表

## 一、怎么触发卡片

用 `<card>` 和 `</card>` 把整个卡片块包起来，**只有这一种写法**：

```
<card>
[Profile|…]
[NPCs]
[NPC|…]
</card>
```

标记必须写完整。**漏掉 `</card>` 不会报错，但会把标记之后的正文一起吞掉**
（被当作卡片内容，因为不符合 `[类型|…]` 格式而不显示）——
所以卡片的输出规则里一定要强调闭合标签，或让卡片块出现在回复最末尾。

## 二、分区名（单独成行，不含竖线）

这几行只是「开关」的作用，告诉渲染器接下来是哪个分区：

```
[Intel]   [NPCs]   [Mails]   [Quests]   [Todos]   [Board]
```

**同义写法也能认**（大小写不敏感）：

| 你写 | 等同 |
|---|---|
| `[Intel]` `[Info]` `[Intels]` | 情报 |
| `[NPCs]` `[NPC]` `[Characters]` `[Cast]` | 人物 |
| `[Mails]` `[Mail]` `[Letters]` | 信件 |
| `[Quests]` `[Quest]` `[Tasks]` `[Task]` | 任务 |
| `[Todos]` `[Todo]` `[Checklist]` | 待办 |
| `[Board]` `[Boards]` `[Posts]` `[Notice]` | 公告 |

**自定义分区名**：写一个不在表里的名字（如 `[其他线索]`），渲染器会**直接用这个名字**做标题。

> 其实分区标题行**可以省略** —— 渲染器靠类型标签自己归类。
> 但建议保留，这样模型填表时更不容易串行。

## 三、类型标签速查

### 1. 名片（全卡只会用一条）

| 标签 | 字段顺序 |
|---|---|
| `Profile` | `姓名` \| `头衔` \| `等级` \| `资源/声望` \| `心境一句话` |

> ⚠️ 注意：`Profile` 特殊，它**不属于任何分区**，会渲染在最上方。
> 字段含义随你定，但**保持 5 个**。

### 2. 该卡特有的字段顺序总表

| 标签 | 归属分区 | 字段顺序（用 `|` 分隔） |
|---|---|---|
| `Pinned` | 情报 | `Emoji` \| `标签` \| `标题` \| `详情` \| `行动指引` |
| `Card` | 情报 | `分类` \| `标题` \| `详情` \| `行动指引` |
| `NPC` | 人物 | `姓名` \| `身份称号` \| `关系/好感` \| `内心独白` |
| `Mail` | 信件 | `发信人` \| `日期` \| `标题` \| `正文` \| `署名` \| `物品名` \| `物品说明` |
| `MainQuest` | 任务 | `标题` \| `进度` \| `说明` \| `奖励` |
| `SideQuest` | 任务 | `标题` \| `状态` \| `说明` \| `奖励` |
| `Todo` | 待办 | `0或1` \| `事项` |
| `Post` | 公告 | `发帖人` \| `身份称号` \| `标签` \| `标题` \| `说明` |
| `Reply` | 公告 | `回帖人` \| `时间` \| `内容` |

> 大小写不敏感，`[NPC|…]` 和 `[npc|…]` 一样。

## 四、两个容易踩的坑

**坑 1：`Todo` 的第 1 个字段是勾选状态，不是文字。**

```
✅ 正确   [Todo|1|去买菜]      ← 已完成，会显示空心点 + 划掉
✅ 正确   [Todo|0|去买菜]      ← 未完成
❌ 错误   [Todo|去买菜]         ← 会把「去买菜」当成勾选状态，事项变空白
```

除了 `0/1`，也认 `true/false`、`是/否`、`√/×`、`已完成`。

**坑 2：字段数量写少了，后面会串位。**

```
模板   [Mail|发信人|日期|标题|正文|署名|物品名|物品说明]
✅ 好   [Mail|老王|三日|问候|近来可好|老王|自制酱菜|腌了三个月]
✅ 好   [Mail|老王|三日|问候|近来可好|老王||]        ← 没礼物就留空，竖线保留
⚠️ 差   [Mail|老王|三日|问候|近来可好|老王]           ← 少两根竖线，虽不报错但后面字段会缺
```

> 好消息：**写少了不会崩，也不会串到别的地方** —— 缺的字段就是空的。
> 所以「礼物留空」这种情况，写成 `[Mail|老王|三日|问候|近来可好|老王||]` 最稳。

## 五、忘了写分区会怎样

比方说你只写了这一行，前面没有 `[NPCs]`：

```
[NPC|伊恩|接待员|好感 72|这人做菜时倒是难得认真]
```

渲染器会**自动把它归到「人物」分区**（因为 `NPC` 这个类型名认得出）。
所以忘写分区标题顶多是顺序不好看，**内容不会丢**。

## 六、用了渲染器不认识的类型

比如你写 `[Hack|目标防火墙|冷却 3 秒|需先断电]`：

- **不会报错，不会丢内容**
- 会平铺显示在一个分区里，标题用你声明过的自定义分区名（没声明就叫「更多」）

所以想加自己的类型，**放心加**。想要更好看的样式，再用上面表里的标准标签。
