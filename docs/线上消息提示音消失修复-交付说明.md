# 线上消息提示音消失 — 交付说明

**版本**：`miya-chat-notify.js v16` ｜ SW 构建 `sw-81` ｜ 日期：2026-02

---

## 一、问题现象

- **线上功能**：AI 回复到了，没有消息提示音。
- **线下功能**：提示音一直正常。
- 用户感受是"以前线上有，现在没了"——提示音功能本身从未被删，是一条**静音判定 bug** 把它吞了。

## 二、根因

线上提示音的完整判定链：

```
新消息到达
 → MiyaChatNotify.notifyAssistantMessages        (chat-notify.js)
   → MiyaMsgSound.playForIncomingMessage          (msg-sound.js)
     → shouldPlayForChat(chatId)
       → isChatRoomForeground(chatId) 为 true ⇒ 静音
```

`isChatRoomForeground`（本次修复前）只看 **DOM 状态**：聊天室 App 开着、没有别的应用盖着，就返回 `true`（"用户正看着，不必响"）。

它漏了一个关键维度——**页面本身是否可见**。只要聊天室是开着的，哪怕用户早就：

- 切到别的 App
- 锁了屏
- 把浏览器切到后台标签

这里依然返回 `true` → `shouldPlayForChat` 据此静音 → **开着聊天室等回复、切出去/锁屏，回复到了却没有提示音**。

### 为什么线下一直正常？

线下反馈音走的是 `playUiFeedback`，只检查"提示音总开关"，**不做前台判定**，所以从不被这条 bug 波及。这正解释了"线下响、线上不响"的不对称现象。

> 补充：`shouldSystemNotify`（系统通知）和 `shouldInAppBanner`（应用内横幅）早就各自做了 `document.hidden` 判断，唯独声音判定链里的 `isChatRoomForeground` 漏了——属于同批逻辑里的一致性缺口。

## 三、修复

`js1/miya-chat-notify.js` — `isChatRoomForeground()` 顶部加一行：

```javascript
function isChatRoomForeground(chatId) {
    /* 【线上提示音修复】页面不可见（切到别的 App / 锁屏 / 切后台标签）时
     * 绝不算"前台"。前台静音的本意是"用户正看着，不必响"，
     * 用户根本没看着就必须响。 */
    if (document.hidden) return false;
    if (!isRoomOpenForChat(chatId)) return false;
    // ……原有 DOM 判定保持不变
}
```

采用 Page Visibility API（`document.hidden`），浏览器/WebView 在切后台、锁屏时会自动置位，无需额外权限。

## 四、修复后的行为矩阵

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 没开聊天室，来消息 | 🔔 响 | 🔔 响（不变） |
| 开着聊天室，正盯着看 | 🔇 静音 | 🔇 静音（设计意图保留） |
| **开着聊天室，切到别的 App** | 🔇 静音（bug） | 🔔 **响** |
| **开着聊天室，锁屏** | 🔇 静音（bug） | 🔔 **响** |
| **开着聊天室，浏览器切后台标签** | 🔇 静音（bug） | 🔔 **响** |
| 聊天室开着但被其它内置应用盖住 | 🔔 响 | 🔔 响（不变） |

同时保留了两条既有联动逻辑（不受影响）：

- 页面不可见时，系统通知（`shouldSystemNotify`）照常弹出；
- 应用内横幅（`shouldInAppBanner`）在页面不可见时本来就不弹（交给系统通知）。

## 五、验证

`node vm` 沙箱测试 `test_notify_sound.js`，4 个场景全部通过：

| # | 场景 | 断言 | 结果 |
|---|---|---|---|
| A | 页面切后台/锁屏 + 聊天室开着 | `isChatRoomForeground === false`（应响） | ✅ |
| B | 页面可见 + 聊天室开着 | `isChatRoomForeground === true`（保留静音） | ✅ |
| C | 页面可见 + 聊天室没开 | `isChatRoomForeground === false` | ✅ |
| D | 其它应用盖住聊天室 | `isChatRoomForeground === false` | ✅ |

另通过 `node --check` 语法校验。
