# 线上思维链气泡泄漏根治 · 交付说明

> 对应反馈：「换了个模型，线上功能里 AI 的思维链用气泡消息发出来，几十个气泡。」
> （与上一轮"线下流式缺字"修复无关，是线上引擎思维链剥离层对新模型输出格式的不兼容。）

## 一、根因

线上生成是三段式：`<thinking>…</thinking> → 正文（每行一气泡）→ <miyavoice>…</miyavoice>`。
气泡拆分（`splitBubbles`）按行切，所以**思维链剥离只要漏掉一次，整条思维链就会按行
拆成几十个气泡**。换模型后新模型的思维链写法只要偏离旧正则的"严格写法"一点点，
剥离就整体失效。用真实引擎源码逐一复现，确认三类泄漏：

### A. 标签变体不匹配（重灾区，7 种形态全泄漏）

旧剥离正则只认 `<thinking>` / `<think>` / `<reasoning>` 这种**无属性、无空格**的写法：

| 泄漏形态 | 例 |
|---|---|
| 别名标签 | `<Thought>…</Thought>`、`<analysis>…</analysis>`、`<scratchpad>`、`<reflection>` |
| 标签内空格 | `<think >…</think >` |
| 带属性 | `<think type="deep">…</think>`（靠"闭标签兜底"侥幸通过，但开标签残行仍在） |
| ◁▷ 包裹 | `◁think▷…◁/think▷` |
| markdown 围栏 | ` ```think … ``` ` |
| 中文标签 | `【思考】…【/思考】` |
| 本体标签 | `<reasoning_content>…</reasoning_content>` |

### B. 未闭合思维链 + 截断（"几十个气泡"的经典来源）

新思维模型的思维链又长又爱分段（段间空行）。当 `<think>` **没闭合**（输出被
max_tokens 截断，或模型忘写闭标签）时，旧兜底逻辑"剥到第一个空行、其后全当正文"
会把**后半条思维链整段保留** → 按行拆成几十个气泡。

### C. 兜底后门

`buildSalvageBubbleText` 的 bare 兜底会把"剥完为空"的原文再裸化捞回 —— 截断场景
（正文根本没开始）下，A/B 剥掉的思维链又被它整条捞回来，前两层白修。

## 二、修复（`js1/miya-chat-engine.js`）

1. **标签变体系统**：`THINK_TAG_ALIASES`（thinking/think/redacted_thinking/reasoning/
   reasoning_content/thought/analysis/scratchpad/reflection/cot/内心/思考/思考过程/心理…）
   × 包裹符（`<>`、`＜＞` 半全角、`◁▷`、`【】`、`[]/［］`、```` ``` ```` 围栏）统一生成
   开/闭正则；开标签允许属性与空格，闭标签允许 `</ think >`、`＜／think＞` 等变体。
   交叉闭合（`<think>…</redacted_thinking>`）天然支持。
   ⚠️ 别名表**故意不含** miyavoice/heartvoice/心声 —— 那是本项目合法功能标签。
2. **截断泄漏根治**：未闭合时旧逻辑"第一个空行之后全保留"改为先取候选段，再用
   `looksLikeOnlineBody`（对白引号/`*动作*`/`（旁白）` 特征浓度 ≥25%）判定：
   像正文才保留，像思维链残留整段剥掉。
3. **两档处理**：尖括号/围栏（真思维链标签）未闭合 → 按截断处理；`【】/[]/◁▷`
   装饰性包裹符未闭合 → **只剥标签本身**（正文里 `[思考]` 这类前缀是合法文本，
   不能整段剥）。成对出现时仍由闭合正则整块剥。
4. **兜底后门封堵**：`buildSalvageBubbleText` bare 分支前先过"未闭合思维段剥离"，
   剥完为空返回空串，让上层按 `empty_reply` 自动重试（最多 3 次）——截断场景的
   正确行为是提示重试，而不是把思维链拆成几十个气泡。
5. **孤立残行过滤**：`splitBubbles` 增加孤立思维标签残行过滤（整行只是一个
   `<think type="x">`、`◁/think▷`、`​```think` 等），这类行成泡只会变成空壳气泡。

## 三、验证（Node 直载真实引擎源码，31/31 通过）

正向（泄漏复现 → 修复后 0 泄漏）16 例：标准 `<think>`/`<thinking>`、闭合+思维链
含空行、**未闭合+思维链多段（截断无正文）**、漏写闭合+正文、`<Thought>`、
`<analysis>`、`<think >`、`<think type="x">`、`◁think▷`、``` 围栏、`<reasoning>`、
`<redacted_thinking>`、全角 `＜think＞`、`【思考】`、`<reasoning_content>` ——
全部只输出正文气泡，思维链零泄漏。

负向回归 15 例：纯正文、`|||` 分隔、正文含 `<3`、正文含 ```js 代码块、正文含
`[思考]` 样文本、变体标签思维链展示提取、`reasoning_content` 字段提取、未闭合围栏
提取、心声模块完整保留、截断场景不再捞思维链、半截正文保住、短叙述正文保守保留、
闭标签带空格兜底、"正文取最后闭合之后"（既有防草稿复读设计）—— 行为全部正确。

ESLint 全量（js1/js2/tools/sw.js）0 告警。
