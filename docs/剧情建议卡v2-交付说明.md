## 三、两个必须说清的技术点（别删）

### 1. `.xw-plot-card` 作用域

设计稿里的 `.wrap` / `.sec` / `.body` / `.choice` 都是极通用类名
（`.choice` 在线下其它地方很容易撞车），直接进全局 CSS 会误伤别处。
所以唯一结构性调整是外面套一层 `.xw-plot-card` 作用域，
**卡内类名、层级、伪元素与设计稿逐字一致**，色值变量也从 `:root`
搬进卡片根（只在本卡生效，不污染全局）。

### 2. 字号免疫（这张卡的老大难，机制沿用 v1 并扩展）

`css/style.css` 的全局规则 `[data-miya-fs] :where(div,button,span,…):not(×10)`
会把**每一个后代元素**的字号强写为 `calc(1em × 倍率) !important`，
多层嵌套反复累积 —— 实测 12px 标题能滚成 48.83px，卡片彻底走形。
两个 `!important` 相撞只比特异性（对家 (0,10,1)），CSS 文件里怎么写都输，
**唯一稳赢的是内联样式 + !important**。

- v2 新增的 `.choice-icon`（1.05em 相对值，必被改写）/ `.choice-text`
  两个真元素 span 也逐个由 JS 内联钉死字号；
- 卡片根继续带 `--miya-font-size-scale:1` 双保险；
- 伪元素（竖条 / 渐隐线 / 箭头）不承载文字，CSS 侧 `font-size:0` 兜底。
- 副作用（刻意接受）：用户调线下字号时卡片不跟随缩放 ——
  这张卡是成品设计，跟着缩必然变形。

### 实测验证（headless Chromium 截图三栏对比）

- ① 设计稿独立版 vs ② 项目真实渲染：布局 / 配色 / 圆角 / 阴影 / 间距一致；
- ③ 全局字号 ×1.25 环境下实测：与 ② 完全一致，免疫补丁生效。

## 四、交互与兼容（零改动确认）

- 点击委托锚点 `data-ap-plot-choice` 原样保留在 button 上
  （`miya-appointment-app` 的 `bindFloorToolsDelegate` 用 `closest` 找它，
  测试钩子 `click(i)` 同样按它索引）—— 换装不影响任何点击行为；
- `<plot>` 解析、上限 6 条 / 单条 120 字、转义、旧数据兜底渲染逻辑全部未动；
- 线下设置里开关「剧情建议」不受影响。
