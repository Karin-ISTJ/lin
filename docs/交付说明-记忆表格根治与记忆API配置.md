## 一、记忆表格「不落库」根治（engine v=10）

### 现象

模型明明在正文后输出了 `<tableEdit>` 记忆格式，表格却一行都没进；而「记忆提炼」（另一个记忆功能）正常生效。

### 根因（实测复现，非猜测）

旧引擎用正则切分写入动作：

```
/(insertRow|updateRow|deleteRow)\s*[（(]\s*([\s\S]*?)\s*[）)]\s*(?=$|;|\n|,|$)/gi
```

结尾的 lookahead 依赖「`)` 之后紧跟分隔符（`;`、换行等）」。但提示词里「正确范例」教模型的相邻动作写法是：

```
<!-- updateRow(...) --><!-- insertRow(...) -->
```

剥掉注释后两条动作之间**只剩空格**，lookahead 落空；实参体又是非贪婪匹配，于是**第二条动作被并进第一条的实参**，参数解析失败，整轮写入全部静默丢弃。用 Node 直跑引擎实测：范例原文只解析出 1 条残缺动作，落库 0 行。

### 修复内容（`js2/miya-memory-table-engine.js`）

| 改动 | 说明 |
|---|---|
| 括号深度扫描切分 | 新增 `extractActionsFromBody`：从动作名的 `(` 起做括号计数，深度归 0 即实参结束；引号状态机（含全角 `“”‘’` 配对）跳过字符串内的括号。动作间无论用什么分隔（空格/分号/换行）都能正确切开 |
| 动作名归一 | 新增 `canonicalActionName`：`INSERTROW`/`UpdateRow` 等大小写变体归一到规范拼写 |
| 多段收集 | `parseTableEditBlock` 从「只认第一段 `<tableEdit>`」改为全局逐段收集（正文一段 + 旁白一段的场景不再丢后半段） |
| 空表首行兜底 | 写入规则教模型「时空表恒定一行，绝不 insertRow」，但空表上照章办事的 `updateRow(0,…)` 会因越界被拒——时空表永远等不到第一行。现在「空表 + 第 0 行」的 updateRow 等价为追加首行 |
| 截断块兼容 | dryRun 的原始标记收集正则补 `$` 兜底：输出被截断（缺 `</tableEdit>`）时不再整段丢失 |
| 附带修复 | 逐段扫描中发现闭合标签匹配正则缺 `g` 标志，`lastIndex` 失效会导致第二段 tableEdit 解析死循环，已一并修复（含 `findTableEditRange` 同类隐患） |

**回归**：`tools/_test_mt.js` 共 **43 项**全部通过（多动作切分、字符串内括号、截断块、多段收集、大小写归一、全角兼容、空表兜底、dryRun、行溯源、参数解析历史用例、注入位置稳定性）。

## 二、「记忆 API」独立配置

### 背景

记忆提炼是**独立于主回复的二次 API 调用**。此前它跟对话 API 共用线路——换主模型/换中转会连带改掉它，且部分中转对同密钥并发限流，主回复进行中再发提炼会被 429 拒掉。

### 使用方法

1. 打开联系人 → 设置页，API 区新增第三栏 **「记忆 API」**（对话 API、语音合成之下）；
2. 填写 **网关地址 / 密钥 / 模型** 三项，点右上角「保存」；
3. 密钥旁的 **⟳** 可拉取模型列表（与对话 API 同款抽屉式选择 + 缓存）。

### 回退规则（`js1/miya-chat-memory-extract.js` 的 `resolveMemoryConfig`）

| 你的配置 | 实际使用的线路 |
|---|---|
| 记忆 API 三项全填 | 记忆专用线路 |
| 只填部分字段 | 缺的项**逐字段**回退对话 API |
| 三项全留空 | 跟随对话 API（若曾配过总结 API，沿用总结 API 老行为）——老用户零迁移 |

### 改动文件

- `js1/miya-chat-memory-extract.js`（v=6）：新增 `resolveMemoryConfig`，提炼请求改走该线路；未配置提示文案同步更新
- `js1/miya-chat-contact-settings.js`（v=100）：新增 `api-memory` 子视图（表单、保存、模型拉取、缓存回填、顶栏保存分发、事件委托共 12 处接入）；配置以嵌套对象 `memoryApi` 存储（与语音合成同模式）

**验证**：解析层 6 场景 + 设置面板 DOM 冒烟 11 项全部通过。

## 三、联系人页版面 + 底栏优化

### 1. 底栏下方露出的滚动内容（怪异观感）

浮动胶囊底栏与屏幕底边之间有一条空隙（安全区 + 8px），滚动内容会从缝里钻出来。现在给 `.soft-tabbar` 加了 `::after` 遮罩：从底栏下沿向下延伸 56px、用页面底色填满、`pointer-events:none` 不拦截任何点击，左右各外扩 14px 盖住圆角边角。

### 2. 群聊大卡压缩

「群聊 / 标签 / 公众号」三个快捷入口从「图标上、文字下」的 78px 高大卡改为**横排胶囊**（图标左、文字右，图标 34→26px），行高压到 52px，首屏不再被大卡占掉近 1/4。窄屏（≤360px）下间距与内边距同步收紧。

### 3. 「特别关注」标题去除

四字标题块已删；星标行容器保留，**没有星标联系人时自动隐藏**（`:empty` 伪类），不再留空白。

### 改动文件

- `index.html`：删除「特别关注」标题块（附注释说明）
- `css/miya-chat-ins.css`（v=59）：快捷胶囊、空容器隐藏、底栏遮罩
