# 农场浇水前后贴图 · 交付说明

> 对应需求：「之前的土地图片作为浇水后的，这个新图片做成浇水前的。」

## 一、改动内容

农场地块从「一张贴图 + 浇水后叠深色」改为**干湿两张专属贴图**：

| 状态 | 贴图 | 说明 |
|---|---|---|
| **浇水前**（含空地、未浇水地块） | `img/farmgame/plot-soil-1.png`（**新增**，512×512 透明底） | 你这次上传的新图——土色偏浅偏干 |
| **浇水后**（`watered=true` 的地块） | `img/farmgame/plot-soil-2.png`（沿用） | 之前的土地图片——土色偏深偏湿 |

- 新图已做与旧图当年相同的处理：**白底转透明（边缘连通域算法，图内白色小花原样保留）→ 裁切贴边 → 缩放 512×512**，与旧图构图规格完全一致。
- 旧机制退役：原先 `.fg-plot.is-watered::before` 的 multiply 深色渐变叠加已删除——现在湿土有真贴图，不再靠滤镜变深。
- 切换逻辑零改动：地块渲染本来就有 `is-watered` 类，只是 CSS 换了背景来源（`css/miya-farmgame.css`）。
- 已实测截图验证：浇水前浅干土、浇水后深湿土，对比鲜明；雨天全田自动浇透、过夜重置后自动回到干土贴图。
