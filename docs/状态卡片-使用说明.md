# 状态卡片 · 使用说明

包里内置了一个**通用卡片渲染器**。它把模型输出里的结构化标记渲染成卡片，
并且**自动跟随你所用的那张角色卡的主题**（颜色、底色、字体都继承，
不会自成一派）。

## 一、怎么开始用

不需要额外导入任何东西 —— 渲染器已经内置在包里。

你只需要**让你用的角色卡按格式输出卡片**。格式分两种写法：

| 写法 | 说明 |
|---|---|
| 行格式 | `[类型\|字段1\|字段2\|…]` |
| 分区行 | 单独一行的 `[分区名]`，表示开启一个分区 |
| 外层包裹 | `<card>…</card>` |

**具体怎么写，看 [`卡片输出规则-可直接粘贴.md`](./卡片输出规则-可直接粘贴.md)** ——
里面有一段写好的世界书条目，整段复制贴进卡里就能用。

## 二、卡片显示在哪里

**在线下（跑楼层）里。**

线下每一层楼里，如果正文里带了手札标记，会渲染成「正文 + 卡片」的排布：
先读剧情，再往下看状态。卡片是**内联在楼层里的**，不是弹出层，也不是独立浮窗。

> 线上聊天（模拟发消息的界面）**不渲染卡片**。线上是短消息、气泡、已读回执那套，
> 长结构化的手札塞进去反而把它撑变形，所以那边保持原样。

## 三、卡片长什么样

以一张通用的冒险卡为例，从上到下依次是：

```
薇拉
[代号·夜莺] [权限 Lv.4] [信用点 9250]
▎雨夜里的霓虹从不撒谎。

🔍 线索更新  三号巷口的黑色轿车
  凌晨 02:14 停留 47 秒
  调取周边探头

情报
  监控残片  门禁日志已破解
  ...
人物
  ⓥ老  老陈  [情报贩子]
     信任 68 / 老交情
     价钱好说，但别问来源

信件 / 任务 / 待办 / 公告 …
```

所有分区**一次性平铺显示**，不做标签页 —— 跑楼层时一眼扫完比分页点开更顺手。

## 四、它是怎么做成「可复用 + 自适应」的

这两点是你明确要求的，实现方式如下：

**1. 可复用**：渲染器不认识任何一张具体的卡。它只认一套通用语法：

- 行格式 `[类型|字段1|字段2|…]`
- 单独的 `[分区名]` 一行表示开启一个分区
- 外层用 `<card>…</card>` 包裹

> 只认 `<card>` 这一个标记。早期版本曾用过另一个标记名，现已不再支持。

已有的类型（按语义映射到固定分区）：`Profile` `Pinned` `Card` `NPC` `Mail`
`MainQuest` `SideQuest` `Todo` `Post` `Reply`。

换成别的卡也能用，两种情况都兜住了：

| 情况 | 表现 |
|---|---|
| 卡用了别的类型名（比如 `[Hack\|…]`） | 不丢内容，落到「更多」分区平铺显示 |
| 卡自己声明了中文分区名（比如 `[其他线索]`） | **直接采用这个名字**，不会被改写成「更多」 |

**2. 自适应原卡**：渲染器不写死任何颜色，全部走 CSS 变量并带兜底：

```css
.xwc {
  --xwc-ink:    var(--xw-ink, currentColor);
  --xwc-soft:   var(--xw-soft, rgba(127,127,127,0.72));
  --xwc-line:   var(--xw-hair, rgba(127,127,127,0.22));
  --xwc-accent: var(--xw-gold, var(--xw-ink, currentColor));
  color: var(--xwc-ink);
  background: transparent;   /* 让原卡背景透出来 */
  font-family: var(--xw-serif, inherit);
  font-size: inherit;
}
```

所以它在不同主题下会自动变色：

| | 博物馆主题 | 手账主题 |
|---|---|---|
| 正文色 | `rgb(20,20,20)` | `rgb(26,26,26)` |
| 分区底色 | `rgb(255,255,255)` | `rgb(250,248,244)` |
| 分隔线 | `rgba(20,20,20,0.09)` | `rgba(26,26,26,0.08)` |
| 金色点缀 | 无 | 有（走 `--xw-gold`） |

如果目标卡**完全没有提供这套变量**，就会回退到一组「最基础的透明样式」
（当前文字色 + 一点半透明分隔线），保证不抢原卡风头。

## 六、验证结果

用**真实离线楼层**跑通（不是注入 HTML，是走 app 自己的渲染管线）：

- 楼层正常渲染，卡片**嵌在楼层 DOM 内**（`.xwc` 在 `.xw-floor` 里）
- 原始标记与原始方括号数据**不再泄漏**成纯文本
- 分区标题正确（情报 / 人物 / 待办 / 其他线索）
- 切换主题后颜色随之变化（自适应生效）
- 多楼层各自渲染卡片，互不影响
- 换成完全无关的另一张卡（赛博朋克侦探）同样能渲染，未识别内容不丢失
- 文档里承诺的每一条行为都逐条实测过（10/10）
- 原有滚动回归 **7/7 通过**，触摸滚动回归 **6/6 通过**

## 七、想用在别的角色卡上

不用改包里的代码 —— 渲染器不认识任何一张具体的卡，只认通用语法。
换卡时**要改的是卡那边**：让新卡的世界书按格式输出卡片。

配套两份文档：

| 文档 | 用途 |
|---|---|
| `卡片输出规则-可直接粘贴.md` | 一段写好的世界书条目，**整段复制**贴进新卡就能用 |
| 同上文件的「格式速查表」部分 | 所有支持的字段与分区名，自己改卡时对照 |

这三条路都兜住了，新卡直接跑：

| 情况 | 表现 |
|---|---|
| 卡用了标准类型（`Profile` `NPC` `Quest`…） | 按语义归入对应分区 |
| 卡自定义了分区名（如 `[其他线索]`） | **原样采用这个名字**，且该分区下的条目不会被类型名抢走 |
| 卡用了没见过的类型（如 `[Hack\|…]`） | 落到「更多」分区平铺，**内容不丢** |

> 唯一需要找我的情况：你想换一套**完全不同的视觉版式**（比如改成分栏）。
> 那是改设计，不是改兼容性。

## 八、一个已知的小事

如果原卡自带「展开手札 / 全屏查看」这类交互按钮，那套交互属于**原卡自己的
HTML 模板**，本渲染器不接管。本渲染器输出的是一份静态排布 ——
在楼层里阅读场景下，静态反而更稳（不会因为沙箱限制导致空白）。
如果你希望恢复折叠/展开交互，告诉我，可以补。
